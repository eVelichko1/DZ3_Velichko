# DZ3_Velichko

Продолжение [DZ2_Velichko](https://github.com/eVelichko1/DZ2_Velichko): консольная программа учёта животных (кошка, собака, утка).

В этом задании программа работает с MySQL:

- **ADD** — создаёт животное и сохраняет его в базу;
- **LIST** — читает полный список из базы;
- **EDIT** — изменяет тип, имя, возраст, вес и цвет выбранного животного;
- **FILTER** — выводит животных выбранного типа;
- **DELETE** — удаляет животное по id;
- **EXIT** — завершает программу.

Таблица `animals` создаётся самой программой при запуске. Отдельно выполнять SQL-скрипт не нужно.

## Что нужно установить

- Java 17 или новее
- Maven
- MySQL 8

## Подготовка MySQL

Пароль ниже — только для локальной базы домашнего задания. В `src/main/resources/db.properties` указаны те же значения: пользователь `otus`, пароль `otus`, база `animals_db`.

Подключитесь к MySQL под администратором и выполните:

```sql
CREATE USER IF NOT EXISTS 'otus'@'127.0.0.1' IDENTIFIED BY 'otus';
CREATE USER IF NOT EXISTS 'otus'@'localhost' IDENTIFIED BY 'otus';
GRANT ALL PRIVILEGES ON *.* TO 'otus'@'127.0.0.1';
GRANT ALL PRIVILEGES ON *.* TO 'otus'@'localhost';
FLUSH PRIVILEGES;
```

Право `CREATE` нужно, чтобы программа сама создала базу `animals_db` при первом запуске.

Если логин или пароль другие, поменяйте `src/main/resources/db.properties`. Те же параметры можно передать переменными окружения `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`.

## Запуск

```bash
mvn -q compile exec:java
```

Пример диалога:

```text
Введите одну из команд (ADD/LIST/EDIT/FILTER/DELETE/EXIT): ADD
Введите тип животного (CAT/DOG/DUCK): CAT
Введите имя животного: Мурзик
Введите возраст животного: 3
Введите вес животного (г): 4200
Введите цвет животного (доступные варианты: белый, чёрный): белый
```

Цвет можно ввести по-русски (`белый`, `чёрный` или `черный`) либо именем константы (`WHITE`, `BLACK`).

Команда **LIST** после перезапуска показывает тех же животных: данные читаются из MySQL, а не из памяти программы. **FILTER** спрашивает тип и выводит только совпавшие записи. **EDIT** и **DELETE** сначала печатают список с `id`, затем просят номер записи.
